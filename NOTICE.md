# Notice and provenance

This repository contains synthetic reference code and invented fixtures for
architecture collaboration. It contains no Foundation Medicine source code,
patient records, configured vendor credentials, or production tenant exports.

The design lineage is recorded in `provenance.json`. Vendor names identify
integration boundaries and public product surfaces. They convey neither vendor
endorsement nor configured-environment qualification.

The phrase “actual implementation” identifies this repository’s role in the
comparative constellation. Evidence records still state whether each claim is
planned, simulated, or observed and whether it is specified, verified,
qualified, validated, or accepted.
