# Repository-local skill catalog

These five skills provide repeatable routes for work that crosses current
source, evidence, recovery, or collaboration boundaries in the Enterprise
Implementation repository. Begin with [`AGENTS.md`](../../AGENTS.md) for the
repository contract, then choose the smallest route that matches the reader
job.

## Choose by reader job

| Reader job | Skill | Useful return |
| --- | --- | --- |
| Reconstruct current source, release, and coordination truth | [`repository-reentry`](repository-reentry/SKILL.md) | One current-state packet and exact re-entry move |
| Identify which source owns a claim or decision | [`source-authority-mapping`](source-authority-mapping/SKILL.md) | A map from contract or source through observation, acceptance, and receiving use |
| Recover from a failed check or stale handoff | [`proportionate-recovery-routing`](proportionate-recovery-routing/SKILL.md) | One bounded recovery action with a changed signal and stopping event |
| Admit a returned database, vendor, or runtime observation | [`configured-environment-evidence-binding`](configured-environment-evidence-binding/SKILL.md) | A coordinate-complete receipt with an explicit evidence ceiling |
| Make cross-repository prose understandable without flattening exact terms | [`contextual-jargon-scan`](contextual-jargon-scan/SKILL.md) | Targeted wording changes and a scoped verification signal |

## Standing and authority

Each skill currently carries the `public_possible` source band. That field
names its review stage rather than a confidentiality boundary. A separate
public-ready review can accept a settled reader job, navigation route, and
portable contract.

Skills route work; they do not replace the sources that establish behavior or
authority. Runnable source and tests own current implementation behavior,
release records own the accepted release, configured receipts own their named
observations, and accountable roles own acceptance and production decisions.

## Return

Close a skill-guided cycle with the changed surface, the smallest observation
that establishes its behavior, the observation's reach and limit, and the role
or repository able to make the next decision. Name the event that makes the
next action ready.
